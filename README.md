# Vocabulary Trainer

Консольное приложение для изучения иностранных слов с использованием коллекций и системы прогресса.

## Возможности

- Создание пользователей
- Создание коллекций слов
- Добавление слов в коллекции
- Удаление слов
- Просмотр коллекций
- Просмотр слов
- Тренировка слов
- Смешивание нескольких коллекций во время тренировки
- Отслеживание прогресса изучения

---

- SQL

## Установка проекта

1. Клонировать репозиторий:

```bash
git clone URL
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Запустить Docker:

```bash
docker compose up -d
```

4. Создать таблицы:

```bash
docker exec -i postgres_master psql -U admin -d vocab_db < sql/schema.sql
```

5. Запустить проект:

```bash
python3 core_service/main.py
```

---

## Очистка базы данных

Для удаления всех данных:

```bash
docker exec -i postgres_master psql -U admin -d vocab_db < sql/reset.sql
```
